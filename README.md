# Student Management System

A simple Java-based Student Management System developed using Core Java.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Calculate Grade
- Display Pass/Fail Status
- Student Data Validation
- Save Student Data to File
- Load Student Data from File

## CRUD Operations

- Create – Add Student
- Read – View and Search Student
- Update – Update Student Details
- Delete – Delete Student

## Technologies Used

- Java
- ArrayList
- Scanner
- File Handling
- VS Code

## Student Details

The system stores:

- Student ID
- Name
- Department
- Year
- Email
- Phone Number
- Marks
- Grade
- Pass/Fail Status

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Compile the program:

```bash
javac Main.java student.java
